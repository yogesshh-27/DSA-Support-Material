Warehouse Graph Network

        
Dual representation of warehouse navigation network: Adjacency List and Adjacency Matrix.

      


      
      

        

          What (Data Structure)
          Adjacency List & Adjacency Matrix
        

        

          Why (Warehouse Relevance)
          Represents physical layout (aisles, racks, bays). Adjacency List is memory-efficient; Adjacency Matrix enables O(1) edge lookup for Floyd-Warshall.
        

        

          Input

          Output
          Linked neighbor map or V × V 2D cost grid

Warehouse Network Optimization – Prim's MST

        
Connect all warehouse locations with minimum total cable, conveyor, or track cost without cycles.

      


      
      

        

          What (Algorithm)
          Prim's Minimum Spanning Tree (Custom Min-Heap)
        

        

          Why (Warehouse Relevance)
          Designs backbone infrastructure (conveyor belts, pneumatic tubes, Ethernet wiring) connecting all zones at minimal installation cost.
        

        

          Input
          Connected Weighted Graph & Optional Starting Node
        

        

          Output
          V-1 Selected MST Edges, Total MST Network Cost
        

        

          Complexity
          Time: O((V + E) log V) Space: O(V + E)
        

      


      
      

        

          Important Viva Distinction (Prim vs Dijkstra):

          • Dijkstra finds the shortest distance from one source to a destination.

          • Prim builds a spanning tree connecting all V vertices with minimum total edge weight sum.

    Academic Scope & Non-Implemented Syllabus Algorithms Rationale
    
        
    
          The following algorithms are part of the standard DSA-II syllabus but were intentionally excluded from the implemented warehouse platform:
        
    
        
    
          
    
            
              
    
                Syllabus Algorithm
                Why Excluded from Active Warehouse Workflow
              
    
                
            
              
    
                Kruskal's Algorithm
                Both Prim and Kruskal compute the MST. Prim was chosen because warehouse networks are localized and dense with a known starting node (Receiving Bay).
              
    
              
    
                Bellman-Ford Algorithm
                Warehouse travel times and physical distances are strictly non-negative. Dijkstra with a Min-Heap solves shortest paths faster (O((V+E)log V) vs O(V·E)).
              
    
              
    
                Warshall's Transitive Closure
                Transitive closure determines mere boolean reachability. In physical warehouses, quantitative movement cost (Floyd-Warshall) is required.
              
    
              
    
                Longest Common Subsequence (LCS)
                LCS is tailored to string/genomic sequence comparisons and has no direct mapping to physical warehouse routing or storage constraints.
              
    
              
    
                Matrix Chain Multiplication (MCM)
                MCM optimizes associative matrix multiplication parenthesization, which does not govern physical material movement or inventory.
              
    
              
    
                Resource Allocation
                0/1 Knapsack directly models weight-limited cart picking, providing a clearer dynamic programming demonstration for warehouse dispatch.
